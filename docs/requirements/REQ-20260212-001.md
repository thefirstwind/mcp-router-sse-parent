# 虚拟项目创建向导 (Virtual Project Wizard)

## 需求来源
为了简化将 Dubbo 服务转化为 MCP 服务的流程，我们需要一个可视化的向导工具，帮助用户通过 Git 仓库或 Maven 坐标快速创建“虚拟项目”。

## 需求分析
用户需要一个易于使用的界面，能够：
1.  解析 Maven POM 文件以获取依赖。
2.  从 Git 仓库提取元数据（JavaDoc、Commit Info）。
3.  自动识别和提取 Dubbo 接口。
4.  使用 AI 补全接口描述。
5.  最终生成 MCP Tool 定义。

## 验收标准
- [ ] 提供基于 Web 的分步向导界面。
- [ ] 支持输入 POM XML 并自动解析依赖。
- [ ] 支持输入 Git URL 并自动克隆代码提取元数据。
- [ ] 后端提供 REST API 支持上述功能。
- [ ] 所有数据模型符合 MCP 协议规范（JSON 兼容）。

## 影响范围
- **模块**: `zk-mcp-parent` (specifically `zkInfo`)
- **新增文件**:
    - `src/main/resources/static/virtual-project-wizard.html`
    - `com.pajk.mcpmetainfo.core.service.PomDependencyAnalyzerService`
    - `com.pajk.mcpmetainfo.core.service.GitRepositoryService`
    - `com.pajk.mcpmetainfo.core.model.wizard.*`

## 实施计划
1.  **数据模型设计**: 定义 DTOs (`GitProjectMetadata`, `PomParseResult` 等)。
2.  **核心服务实现**:
    - `PomDependencyAnalyzerService`: 解析 Maven 依赖。
    - `GitRepositoryService`: 克隆和管理 Git 仓库。
    - `JavaDocParserService`: 提取 JavaDoc。
3.  **前端实现**: 创建 `virtual-project-wizard.html`。
4.  **集成测试**: 验证流程闭环。
